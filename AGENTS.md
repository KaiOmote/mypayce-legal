# Legal-site maintenance rules

- This is a public draft repository. Never commit residential addresses, personal phone numbers, identity documents, receipts, API keys or private operator details.
- MyPayce is the public app/trade name, not a fabricated company or confirmed legal-operator identity. Required operator disclosure remains a publication blocker until reviewed.
- Audit actual app behavior before changing privacy or purchase claims. Record the application commit and distinguish code evidence, provider documentation and unverified dashboard/device behavior.
- Preserve the promised current/future Local Pro coverage for Lifetime; no unilateral limitation may silently remove it.
- Keep EN/JA section identities and material meaning aligned. Do not invent governing law, legal approval, response deadlines, retention schedules or universal compliance.
- The audience is international; planned App Store distribution excludes the 27 EU member states. Japan/US are primary research references, not exclusive markets.
- Only docs/ is intended for Pages. Keep review notes outside it. No trackers, cookies, browser storage, runtime scripts, forms, external fonts or third-party embeds.
- Use the shared static generator and CSS. Run npm run build and npm run check after content changes. No dependency installation is needed.
- Do not enable Pages, change repository settings, merge or publish until the owner approves the final documents. Draft/noindex notices are not confidentiality controls.
- Keep NewMoneyPace read-only. Do not change EAS, App Store Connect, RevenueCat, builds, submissions or OTA releases from this task.
- Do not start a persistent preview server or browser/app instance without explicit authorization. Report physical/rendered visual QA as unverified if not performed.
